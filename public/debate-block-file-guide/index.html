What is a block file

A block file is a collection of pre-written responses to common arguments. It saves prep time and improves response quality in round.

How to organize blocks

Organize by clash, not by topic. Each clash should have blocks for both sides so you are ready regardless of which side you are assigned.

Using AI to build blocks

DebateLab can help you brainstorm likely arguments and draft initial blocks. Verify the logic and evidence before using them in round.

No. Private dashboards and account routes should remain noindexed while public guides provide crawlable context.
