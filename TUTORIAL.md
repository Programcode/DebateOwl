# DebateLab Guide

## Managing AI Providers
DebateLab supports OpenAI, Anthropic, and Google Gemini.
*   **Gemini 3 Flash** is the recommended default for most tasks due to speed and context size.
*   **Grounding:** Enable/Disable specific providers in **Settings**.

## Using the Source Library
The Library is the "Brain" of your project.
1.  **Add URLs:** Paste links into the Ask chat or Factoids search.
2.  **Bookmark:** Click the Bookmark icon on AI responses to save them as sources.
3.  **Toggle:** Use the switches in the **Library** page to choose which research the AI should use for current tasks.

## Admin Features
Entering the code `debate2026` in Settings unlocks:
1.  **Global System Prompt:** Tell the AI how to behave across the entire app (e.g., "Adopt a highly aggressive British Parliamentary tone").
2.  **System Keys:** Use the pre-configured keys from `config.js`.
3.  **Database Reset:** Instantly wipe all local history if switching motions.

## Exporting Work
Once you've generated a case, click **Export Word** to get a formatted document ready for printing or sharing.
