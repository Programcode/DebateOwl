Add an authenticated E2E assertion for nav-to-heading agreement in each locale.

   Likely files: `src/components/layout/AppLayout.tsx`, the five feature pages, `src/locales/{en,es,hu}.json`, and `e2e/quality-backlog.spec.ts`.

4. **Selected Flowchart node deletion has no success feedback in `src/pages/FlowchartPage.tsx:337-341`**

   `deleteSelectedNode` removes the node and connected edges immediately, but it neither confirms the action nor reports success. Add a focused confirmation or undo path appropriate for the editor, then show a localized success/error toast and cover both paths in a new `src/test/pages/FlowchartPage.test.tsx`.    Likely files: `src/pages/FlowchartPage.tsx`, `src/locales/{en,es,hu}.json`, new `src/test/pages/FlowchartPage.test.tsx`, and `e2e/quality-backlog.spec.ts`.
