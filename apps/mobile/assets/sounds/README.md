# Timer sounds

`beep.wav` (one minute left) and `double-beep.wav` (time up) are generated by
[scripts/render-timer-sounds.ts](../../scripts/render-timer-sounds.ts), which
copies the website's Web Audio synth in `src/pages/TimerPage.tsx`: an 880 Hz
sine at 22.05 kHz, 16-bit mono. Rerun the script to change them; don't edit
the files by hand.
