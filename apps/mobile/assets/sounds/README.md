# Timer sounds

`beep.wav` (one minute left), `double-beep.wav` (time up) and `knock.wav`
(points of information open or close) are generated by
[scripts/render-timer-sounds.ts](../../scripts/render-timer-sounds.ts), which
copies the website's Web Audio synth in `src/lib/timer-signals.ts`: an 880 Hz
sine for the beeps and two 180 Hz triangle taps for the knock, at 22.05 kHz,
16-bit mono. Rerun the script to change them; don't edit the files by hand.
